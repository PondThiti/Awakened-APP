## 1. เป้าหมายและหลักการ

### เป้าหมาย
1. รู้จักผู้ใช้พอที่จะสร้างเควสต์วันแรกให้ **ทำได้จริงและรู้สึกว่าเป็นของเรา**
2. แยกผู้ใช้ตามสายหลัก: **💪 Strength & Physique**, **🧠 Iron Discipline**, **⚡ Full Awakening** โดยจุดประสงค์รวมคือ **ออกกำลังกายและพัฒนาตัวเอง**
3. **จุดประกายแรงจูงใจ** ตั้งแต่นาทีแรกผ่านการให้ผู้ใช้ค้นหา "บอสใหญ่" และเหตุผลของตัวเอง
4. ให้ผู้ใช้ตัดสินใจเริ่มด้วยตัวเอง แล้วจบด้วยเควสต์แรกที่ทำเสร็จได้ภายในไม่กี่นาที

### หลักการ (สอดคล้อง P1–P8 ในเอกสารหลัก)
| หลักการ | ความหมายในแบบสอบถาม |
|---|---|
| ปลุกใจ ไม่ใช่กดดัน | แรงกระแทกมาจากเป้าหมายและภาพอนาคต ไม่ใช่การทำให้รู้สึกผิดหรือเปรียบเทียบกับคนอื่น |
| ข้ามได้ | ทุกข้อ (ยกเว้นอายุ) มีตัวเลือก "ข้าม/ไม่ระบุ" และมีค่าเริ่มต้นที่ปลอดภัย |
| ถามเท่าที่จำเป็น | ถามเฉพาะสิ่งที่เปลี่ยนเควสต์จริง ๆ |
| ปลอดภัยไว้ก่อน | ข้อมูลอายุ/สุขภาพใช้ "ลดความหนัก" เสมอ ไม่ใช้ "เพิ่มความหนัก" |
| ตอบใหม่ได้ทุกเมื่อ | แก้ไขได้ที่ Profile → "ปรับแผนของฉัน" |
| ข้อมูลอยู่ในเครื่อง | คำตอบไม่ถูกส่งออก ลบได้ในตั้งค่า |

## 2. ภาพรวมโครงสร้าง (4 ช่วง)

```
ช่วง 1  Player Profile & Class         Q1–Q4    ใช้เวลาคิด ≤ 2 วินาที/ข้อ  เริ่มมีส่วนร่วม
ช่วง 2  Emotional Trigger              Q5–Q9    ปลุกไฟ + หน้าจอดำคั่นอารมณ์ (หลัง Q7)
ช่วง 3  Base Stats & Constraints       Q10–Q18  ข้อมูลเชิงปฏิบัติการ คำนวณระดับความยาก
ช่วง 4  Awakening & Commitment         Q19–Q21  เควสเสริม + เสียงผู้นำทาง + คำปฏิญาณกดค้าง
   ↓
Status Window (Awakening Profile) + เควสต์วันแรก
```

**เหตุผลของลำดับ:** ถามเรื่องเบา ๆ ก่อน → ให้เลือกสาย (รู้สึกเป็นตัวละคร) → เข้าอารมณ์ตอนที่ผู้ใช้ลงทุนตอบมาแล้ว → ถามข้อมูลจริงขณะที่ใจร้อนอยากเริ่ม → ปิดด้วยพันธสัญญาและรางวัลทันที

## 4. รายละเอียดช่วงปลุกอารมณ์

เป้าหมายคือให้ผู้ใช้รู้สึกว่า **นี่คือจุดเริ่มต้นของตัวเอง** ไม่ใช่กรอกฟอร์ม โดยใช้ธีม "ตื่น" ตามชื่อแอป

### 4.1 หน้าเปิด (Welcome)
```
[หน้าจอมืด มีแสงริบหรี่ที่กลางจอ]

   "บางส่วนของคุณยังหลับอยู่"
   "และบางส่วนกำลังรอให้วันนี้มาถึง"

        [ เริ่มปลุก ]
```
เมื่อกด แสงสว่างขึ้นทีละนิด เสียงเบา ๆ (ปิดได้) และเคารพการตั้งค่า "ลดแอนิเมชัน"

### 4.2 วงแหวน "สว่างขึ้น" ระหว่างตอบ
ทุกช่วงที่ตอบ วงแหวน XP รอบไอคอนเต็มขึ้นหนึ่งส่วน และแสงของหน้าจอสว่างขึ้น (แทนตัวเลข "ข้อ x/21")

### 4.3 หน้าจอดำคั่นอารมณ์ (Interstitial — แทรกหลัง Q7)
พื้นหลังดำ ข้อความทยอยปรากฏ (ข้อความของโนม คงไว้ตามต้นฉบับ):

> **"รู้ไหม? คนส่วนใหญ่ไม่ได้ล้มเหลวเพราะอ่อนแอ แต่ล้มเหลวเพราะใช้ 'อารมณ์' นำทางแทนที่จะใช้ 'ระบบ'..."**
> **"นับจากวินาทีนี้ ระบบจะเปลี่ยนเป้าหมายของคุณให้กลายเป็นเควสที่จับต้องได้ในทุก ๆ วัน"**

ปุ่ม: **[ ต่อไป ]** (กดได้หลังข้อความขึ้นครบ ~3 วินาที หรือกดข้ามได้ทันที)

> ข้อความนี้ดีเพราะบอกผู้ใช้ว่า "ปัญหาไม่ได้อยู่ที่ตัวคุณ" ซึ่งสนับสนุนหลักไม่ตำหนิตัวเอง จึงเหมาะเป็นจุดเปลี่ยนอารมณ์จาก "รู้สึก" เป็น "ลงมือ"

### 4.4 เสียงผู้นำทาง (Narrator, Q20)

### 4.5 ปุ่มคำปฏิญาณ (Q21)
```
   "ฉัน [ชื่อ] ขอเริ่มตื่นขึ้น ณ วันนี้
    ไม่ใช่เพื่อสมบูรณ์แบบ แต่เพื่อก้าวต่อไปทีละวัน"

     [ กดค้าง 3 วินาทีเพื่อตื่น ]   ← วงแหวนค่อย ๆ เต็ม + สั่น Haptic ไล่ความแรง
```
- ขณะกดค้าง: วงแหวนเต็มทีละน้อย + Haptic แบบไล่ระดับ (ปิดได้) เมื่อครบ 3 วินาที: แสงวาบ + เสียง + แสดง Status Window
- **ทางเลือกการเข้าถึง:** ผู้ใช้ที่ลดแอนิเมชัน/ใช้ TalkBack/มีข้อจำกัดการกดค้าง ใช้ปุ่ม "ยอมรับพันธสัญญา" แบบกดครั้งเดียวแทน
- ปุ่มรอง **"ยังไม่พร้อมตอนนี้ — กลับมาเมื่อไรก็ได้"**: บันทึกคำตอบทั้งหมด เข้าแอปด้วยค่าเริ่มต้นปลอดภัย (ข้อ 10.3) ไม่มีข้อความตำหนิหรือถามซ้ำ

### 5.3 ระบบค่าสถานะ (Stats) — จากร่างของโนม
| Stat | ชื่อ | เพิ่มจากเควสต์ประเภท | ค่าเริ่มต้นมาจาก |
|---|---|---|---|
| **STR** | พละกำลัง (Strength) | วิดพื้น สควอต เวท แพลงก์ กลุ่มกล้ามเนื้อ | Q11 (วิดพื้น) + Q10 |
| **VIT** | ความอึด/ชีวิตชีวา (Vitality) | เดิน วิ่ง ปั่น ว่ายน้ำ ดื่มน้ำ นอนหลับ ยืดเหยียด | Q10 + Q16 (พลังงาน) |
| **INT** | ปัญญา (Intellect) | อ่านหนังสือ เรียนรู้ Pomodoro จด Journal | Q19 (เลือกเรียนรู้/อ่าน) |
| **WIL** | วินัย/จิตใจ (Willpower) | ตื่นตรงเวลา งดโซเชียล อาบน้ำเย็น นอนตรงเวลา ทำครบตามแผน | Q6 (ถ้าบอสคือวินัย ค่าเริ่มต้นต่ำ) + Q19 |

**กติกาของ Stats (สำคัญ):**
- เป็น **ตัวแสดงความก้าวหน้า** ไม่ใช่การให้คะแนนสุขภาพ และไม่ใช้เปรียบเทียบกับผู้ใช้อื่น
- ค่า **ไม่ลดลง** เมื่อพลาดวันหรือพัก (หลักไม่ลงโทษ)
- เพิ่มทีละน้อยตามจำนวนเควสต์ที่ทำสำเร็จในหมวดนั้น มีเพดานรายวันเหมือน XP
- ใช้ปลดล็อกเหรียญตรา/ฉายา (เช่น "ใจเหล็ก" เมื่อ WIL ถึงระดับหนึ่ง) แต่ **ไม่ผูกกับสูตร XP/Level** เพื่อไม่ให้ซับซ้อนใน Phase 1

## 6. ตรรกะสร้าง Daily Quest

### 6.1 โครงสร้างเควสต์ประจำวัน
ทุกวันสร้าง **3 เควสต์หลัก + 1 โบนัส (ไม่บังคับ)** ปรับเป็น 2–5 ได้ในตั้งค่า

| ช่อง | ชนิด | Stat ที่เพิ่ม | ตัวอย่าง |
|---|---|---|---|
| ช่อง A | **Body** (ร่างกาย) | STR / VIT | เดิน 15 นาที, วิดพื้น, สควอต, เบอร์พี |
| ช่อง B | **Mind/Discipline** (วินัย-ใจ) | WIL / INT | Pomodoro, ไม่กดเลื่อนปลุก, งดไถโซเชียล, อ่านหนังสือ |
| ช่อง C | **Foundation** (พื้นฐานชีวิต) | VIT | ดื่มน้ำตามเป้า, เข้านอนตามเวลา, บันทึกอาหาร |
| โบนัส | ตามคำตอบ Q6/Q19 | ตามชนิด | เควสต์ต้านบอส หรือวินัยเสริมที่ผู้ใช้เลือกใน Q19 |

เควสต์วินัยที่ผู้ใช้เลือกใน Q19 จะถูก **หมุนเวียนเข้าช่อง B และโบนัส** ตลอดสัปดาห์ (ไม่ใส่ครบทุกข้อทุกวันเพื่อไม่ให้ล้นมือ)

### 6.2 สัดส่วนตามสาย (Q4)
| สาย | Body | Mind | Foundation | เควสต์เด่นรายสัปดาห์ |
|---|---|---|---|---|
| 💪 Strength & Physique | 50% | 20% | 30% | ท้าทายร่างกาย 1 ครั้ง (Volume Challenge) |
| 🧠 Iron Discipline | 20% | 50% | 30% | ท้าทายวินัย 1 ครั้ง |
| ⚡ Full Awakening | 35% | 35% | 30% | สลับร่างกาย/วินัยตามสัปดาห์ |

ทุกสายต้องมี Body อย่างน้อย 1 ข้อต่อวัน (ยกเว้นวันพักตามแผน) เพราะจุดประสงค์หลักของแอปคือออกกำลังกายและพัฒนาตัวเอง

### 6.3 คะแนนระดับเริ่มต้น (Starting Tier 1–4)
```
score = freq(Q10) + pushup(Q11) + energy(Q16) + path_bonus − boss_penalty
  freq:    แทบไม่เลย=0, 1–2 ครั้ง=1, 3–4 ครั้ง=2, หนักเกือบทุกวัน=3
  pushup:  <5 หรือวางเข่า=0, 5–15=1, 16–30=2, >30=3, ข้าม/ไม่แน่ใจ=0
  energy:  1–2=0, 3=1, 4–5=2
  path_bonus: Iron Discipline = 0 (เริ่มจากวินัยก่อน), อื่น ๆ = 0
  boss_penalty: ถ้า Q6 มี "ไฟมอดไว" หรือ "ไร้ทิศทาง" → −1

tier = clamp( 1 + floor(score / 3), 1, 4 )
```
| Tier | ความหมาย | ตัวอย่าง Body |
|---|---|---|
| 1 | เริ่มต้นเบามาก (Micro) | เดิน 10 นาที, ยืดเหยียด 5 นาที, วิดพื้นวางเข่า/กำแพง |
| 2 | พื้นฐาน | เดิน 20 นาที, สควอต 2×10, วิดพื้น 3×5 |
| 3 | ปานกลาง | วิดพื้นรวม 50 ครั้ง (แบ่งเซต), แพลงก์รวม 3 นาที, เบอร์พี 20 ครั้ง |
| 4 | จริงจัง | เวิร์กเอาต์ตามตารางกล้ามเนื้อ 45 นาที |

**ข้อสำคัญ:** ถ้าไม่แน่ใจ **ลดลง 1 ขั้น** เสมอ ผู้ใช้ปรับขึ้นเองได้ภายหลัง

### 6.6 กฎประกอบเควสต์ (Rule Engine แบบง่าย)
```
for each day:
  1. กรองคลังเควสต์ด้วย: tier, เวลา (Q13), สถานที่ (Q12), กิจกรรมที่ชอบ (Q18),
     โหมดความปลอดภัย (Q15), กฎอายุ (Q2)
  2. จัดช่อง A/B/C ตามสัดส่วน (6.2) แล้วสุ่มถ่วงน้ำหนักด้วยแท็ก
     (บอส Q6, วินัยเสริม Q19)
  3. ถ้า 7 วันแรก และมี "ไฟมอดไว" → บังคับใช้ Micro-Quests (Quick Wins Mode)
  4. หลีกเลี่ยงซ้ำกับเมื่อวานเกินครึ่ง
  5. ตรวจเวลารวม ≤ เวลาที่ผู้ใช้ให้ ถ้าเกินให้ลดความยาว/เปลี่ยนเป็น Micro
  6. ถ้าเป็นวันพักตามแผน → ใช้ชุด Recovery
  7. ถ้าพลาดติดต่อกัน ≥ 2 วัน → วันถัดไปเป็น Comeback Quest (6.8)
  8. ผู้ใช้สลับเควสต์ได้ 1 ครั้ง/วัน
```

### 6.7 Progressive Overload และการปรับตัว (ทุก 7 วัน)
| สถานการณ์ | ข้อเสนอ (ผู้ใช้ยืนยันเสมอ) |
|---|---|
| ทำสำเร็จ ≥ 80% ครบ 7 วัน | **เสนอเพิ่มเป้า** เช่น วิดพื้น 10 → 12 ครั้ง, เดิน 15 → 18 นาที (เพิ่มทีละไม่เกิน ~10–20%) หรือขึ้น 1 tier |
| ทำสำเร็จ < 40% ติดต่อกัน 5 วัน | "ลองลดให้เบาลงไหม?" ไม่หัก XP ไม่มีข้อความตำหนิ |
| ข้ามเควสต์ชนิดเดียวกัน 3 ครั้ง | "ไม่ถูกใจเควสต์แบบนี้ใช่ไหม? เปลี่ยนเป็นแบบอื่นได้" |
| ครบทุก 7 วัน | Check-in 3 ข้อสั้น (ข้อ 6.9) |

### 6.8 Comeback Quest (แทน Penalty Quest)
| | Penalty Quest (ร่างเดิม) | **Comeback Quest (ฉบับนี้)** |
|---|---|---|
| ทริกเกอร์ | ขาดส่งเควสต์ | พลาดติดต่อกัน ≥ 2 วัน หรือกลับมาหลังหายไป |
| เนื้อหา | ทำเพิ่ม/ลงโทษ | **เบากว่าปกติ**: 1 เควสต์ Micro + 1 เควสต์ใจ (เช่น หายใจลึก ๆ 1 นาที) |
| รางวัล | — | +15 XP "กลับมาแล้ว" (จำกัด 1 ครั้ง/7 วัน กันเจตนาข้ามเพื่อรับ) |
| ผลต่อ XP/Level | หัก/ลงโทษ | **ไม่มีการหักใด ๆ** |
| ข้อความ | ตำหนิ | "ยินดีต้อนรับกลับ เริ่มเบา ๆ ก่อนก็ได้" |

### 6.9 Check-in รายสัปดาห์ (3 ข้อสั้น)
1. "สัปดาห์นี้ความหนักของเควสต์เป็นอย่างไร?" — เบาไป / พอดี / หนักไป
2. "เวลาที่ให้ได้จริงเป็นอย่างไร?" — เท่าเดิม / น้อยลง / มากขึ้น
3. "อยากเปลี่ยนอะไรไหม?" — (ข้อความ ข้ามได้)

## 8. กฎความปลอดภัยและจริยธรรม

### 8.1 อายุ (Q2)

| 18–54 | ใช้ตรรกะปกติ |
| 55+ | เน้นความแข็งแรงของข้อ ทรงตัว ยืดเหยียด และวันพักที่เพียงพอ ลดแรงกระแทก |

> เก็บอายุเป็น "ช่วงอายุ" เท่านั้น (ไม่เก็บวันเกิด) และเก็บในเครื่องเท่านั้น

### 8.2 โหมดความปลอดภัยด้านร่างกาย (Q15)
| คำตอบ | พฤติกรรมของแอป |
|---|---|
| ไม่มี | ปกติ |
| เคยบาดเจ็บ/ปวดเข่า หลัง ข้อ | ตัดท่ากระโดด/แรงกระแทกสูง เสนอทางเลือกแรงกระแทกต่ำ |
| กำลังบาดเจ็บอยู่ | เควสต์ Recovery/ยืดเหยียดเบา + แนะนำให้ปรึกษาผู้เชี่ยวชาญก่อนออกกำลังกาย ข้าม Q11 |
| แพทย์เคยแนะนำให้จำกัด | เควสต์เบาเท่านั้น + "ควรทำตามคำแนะนำของแพทย์เป็นหลัก" ซ่อนอาบน้ำเย็น ข้าม Q11 |
| ตั้งครรภ์/หลังคลอด | ชุดเบา + แนะนำให้ปรึกษาแพทย์ก่อนเริ่ม ซ่อนอาบน้ำเย็น ข้าม Q11 |
| ไม่แน่ใจ/ไม่ระบุ | เริ่มเบา (ลด 1 ขั้น) พร้อมข้อความ "ฟังร่างกายตัวเอง หยุดถ้าปวดหรือเวียนหัว" |

**ข้อความที่ต้องแสดงตอนเริ่ม:** *"Awakened ไม่ใช่เครื่องมือทางการแพทย์ หากมีโรคประจำตัวหรืออาการผิดปกติ ควรปรึกษาแพทย์ก่อนเริ่มออกกำลังกาย"*

**ข้อความเตือนของเควสต์อาบน้ำเย็น:** *"ไม่เหมาะกับบางคน เช่น ผู้มีโรคหัวใจหรือความดัน หากไม่แน่ใจให้ข้ามเควสต์นี้หรือปรึกษาแพทย์ เริ่มจากน้ำที่เย็นพอทนและเวลาสั้น ๆ"*

### 8.3 สิ่งที่ **ไม่ถาม** และเหตุผล
| ไม่ถาม | เหตุผล |
|---|---|
| น้ำหนัก ส่วนสูง BMI | กระตุ้นความกังวลเรื่องรูปร่างได้ง่าย และไม่จำเป็นต่อการสร้างเควสต์แบบเน้นพฤติกรรม (ถ้าอยากให้บันทึก ให้เป็นตัวเลือกภายหลังและปิดได้) |
| เป้าหมายลดน้ำหนักเป็นกิโลกรัม/ภายในกี่วัน | ไม่ส่งเสริมเป้าหมายที่ผลักให้ทำเกินร่างกายรับไหว |
| ภาพถ่ายร่างกายก่อน-หลัง | ความเสี่ยงต่อภาพลักษณ์ตนเองและความเป็นส่วนตัว |
| รายละเอียดโรคประจำตัว/ยา | ไม่จำเป็น เก็บแค่ธงกว้าง ๆ (Q15) |
| ประวัติการกินผิดปกติ/โรคทางจิต | เกินขอบเขตแอป ไม่ควรให้แอปประเมิน |

### 8.4 ความอ่อนไหวทางอารมณ์
- คำถามช่วงปลุกอารมณ์ (Q5–Q9) **ข้ามได้** และข้อความที่ผู้ใช้พิมพ์เป็นข้อมูลส่วนตัว
- แอป **ไม่วิเคราะห์หรือวินิจฉัยอารมณ์** จากคำตอบหรือข้อความที่พิมพ์ ใช้เพียงแสดงกลับให้ผู้ใช้เห็น
- ถ้าผู้ใช้พิมพ์ข้อความที่ดูเหมือนอยู่ในภาวะทุกข์ใจหนัก แอปไม่ตอบโต้เชิงวิเคราะห์ แต่มีหน้า **"ขอความช่วยเหลือ"** ที่เข้าถึงง่ายเสมอ (เตรียมช่องทางที่ถูกต้องตามประเทศก่อนเผยแพร่)

### 8.5 ความเป็นส่วนตัว
- ข้อมูลทั้งหมดเก็บในเครื่อง ไม่ส่งออก
- ก่อน Q15 แสดง: *"ข้อมูลนี้เก็บเฉพาะในเครื่องของคุณ ใช้เพื่อเลือกเควสต์ที่ปลอดภัยเท่านั้น ข้ามได้"*
- ลบคำตอบทั้งหมดได้ที่ ตั้งค่า → ข้อมูลและความเป็นส่วนตัว

### 8.6 สิ่งที่ห้ามทำ (Dark Patterns)
- ❌ ไม่ใช้ตัวนับเวลาหลอก ๆ หรือข้อเสนอจำกัดเวลา
- ❌ ไม่ซ่อนปุ่มข้ามหรือทำให้รู้สึกผิดเมื่อกดข้าม/ปฏิเสธ
- ❌ ไม่ใช้คำตอบของผู้ใช้เพื่อเปรียบเทียบกับผู้ใช้อื่น
- ❌ ไม่เก็บคำตอบเพื่อใช้อย่างอื่นนอกจากสร้างเควสต์
- ❌ ไม่มีบทลงโทษ (หัก XP/Level/Stats) ทุกกรณี

### 9.2 โครงสร้างแท็กของเควสต์ (ต่อยอด `quests.json`)
```json
{
  "id": "body_pushup_micro",
  "type": "daily",
  "slot": "body",
  "stat": "STR",
  "title_th": "วิดพื้น 10 ครั้ง (วางเข่าได้)",
  "tier": [1],
  "duration_min": [2, 5],
  "micro": true,
  "requires": { "equipment_any": ["bodyweight", "home_gym", "full_gym"] },
  "excludes": { "safety_flags": ["injured_now", "medical_limit", "pregnancy"], "age_band": [] },
  "boosts": { "bosses": ["fading_fire", "no_time", "drained"], "path": ["strength", "full"] },
  "reward_xp": 20
}
```
- `requires` = ต้องผ่านจึงเข้ากลุ่มที่เลือกได้
- `excludes` = ถ้าตรงตัดออก (ความปลอดภัยและอายุ)
- `boosts` = เพิ่มน้ำหนักการสุ่ม
- `stat` = ค่าสถานะที่เพิ่มเมื่อทำสำเร็จ

### 9.3 Pseudo-code ตัวเลือกเควสต์
```dart
List<Quest> pickDaily(OnboardingProfile p, List<QuestTemplate> pool, DayContext ctx) {
  final quickWins = ctx.now.isBefore(p.quickWinsUntil) && p.bosses.contains(Boss.fadingFire);

  final eligible = pool.where((q) =>
      q.tier.contains(p.effectiveTier) &&
      (!quickWins || q.micro) &&
      q.matchesEquipment(p.equipment) &&
      !q.isExcludedBy(p.safetyFlags, p.ageBand) &&
      q.fitsTime(p.minutesPerDay)).toList();

  final picks = <Quest>[];
  for (final slot in [Slot.body, Slot.mind, Slot.foundation]) {
    picks.add(weightedPick(
      eligible.where((q) => q.slot == slot),
      boost: (q) => q.boostScore(p.bosses, p.disciplinePicks, p.path),
      avoid: ctx.yesterdayIds,
    ));
  }
  if (ctx.missedDaysInRow >= 2) return comebackSet(p, pool);   // ไม่ลงโทษ
  return fitIntoTime(picks, p.minutesPerDay);
}
```
> เป็น **Pure Dart ไม่พึ่ง UI** ทดสอบด้วย Unit Test ได้ สอดคล้องหลักแยก Engine ในเอกสารหลัก

## 12. คำถามที่ต้องตัดสินใจต่อ

1. **จุดที่ปรับจากร่างของโนม (ข้อ 0.3)** ยอมรับทั้ง 4 ข้อหรือไม่? ถ้าอยากกลับไปใช้ต้นฉบับข้อไหนบอกได้ (ยกเว้นข้อที่เกี่ยวกับความปลอดภัยของผู้เยาว์ ยูนะแนะนำให้คงไว้)
2. **จำนวนข้อ:** ตอนนี้ 21 ข้อ ใช้เวลา ~4 นาที ถ้าอยากสั้นลง ตัดได้ที่ Q9, Q17, Q18 กระทบน้อยที่สุด (ทั้งสามเป็นข้อไม่บังคับ)
3. **ระบบ Stats (STR/VIT/INT/WIL):** ตอนนี้เป็นตัวแสดงผลและปลดล็อกเหรียญตราเท่านั้น จะให้ Stats มีผลกับเควสต์หรือรางวัลมากกว่านี้ไหม (แนะนำเก็บไว้ Phase 2 เพื่อไม่ให้ Phase 1 ซับซ้อน)
4. **ผู้ใช้อายุ 13–17:** รองรับตั้งแต่เวอร์ชันแรกหรือรอทำชุดเควสต์เฉพาะก่อน
5. **คลังเควสต์:** ต้องเขียนประมาณ 100–150 ข้อ (Body/Mind/Foundation × 4 tier + Micro + Comeback + เควสต์วินัยทั้ง 9 แบบใน Q19) ให้ยูนะร่างชุดแรกต่อไหม

## 2. กติกาของถ้วยรางวัล

ข้อที่ต้องยึดเหมือนกันทุกถ้วย ตรงกับหลักการในเอกสารหลัก (ไม่ลงโทษ ปลอดภัยไว้ก่อน ข้อมูลอยู่ในเครื่อง)

| # | กติกา |
|---|---|
| R1 | **ถ้วยที่ได้แล้วอยู่ถาวร** ไม่ถูกเพิกถอน แม้ Streak ขาด พักยาว หรือลบกิจกรรมเก่าทิ้งภายหลัง |
| R2 | **ไม่มีถ้วยที่ผูกกับน้ำหนัก แคลอรี สัดส่วนร่างกาย การอดอาหาร หรือการ "ห้ามพัก"** ถ้วยอาหารให้รางวัลที่การบันทึกเท่านั้น |
| R3 | **วันพักมีถ้วยของตัวเอง** (หมวดพื้นฐานชีวิตและการพัก) และวันพักตามแผนนับรวมใน Streak กับ Weekly Consistency |
| R4 | **ไม่นับกิจกรรมที่เพิ่มย้อนหลังเกิน 24 ชั่วโมง** ตามกฎข้อ 7.6 ใน `Awakened.md` |
| R5 | **มีเพดานการนับต่อวัน** กันกรอกตัวเลขเกินจริงและกันไม่ให้ถ้วยดันคนออกกำลังกายเกินตัว ค่าเริ่มต้น: วิดพื้น 300 ครั้ง, สควอต 500 ครั้ง, แพลงก์ 30 นาที, ระยะทาง 100 กม., เวลาออกกำลังกาย 180 นาที, น้ำนับ 5 ครั้ง, Pomodoro 8 รอบ |
| R6 | **Streak นับวันพักตามแผนและวันที่ใช้ Freeze** ตรงกับข้อ 9.2 ใน `Awakened.md` |
| R7 | **ไม่มีการเทียบกับผู้ใช้อื่น** ไม่มีเปอร์เซ็นต์ "คุณอยู่ในกลุ่มที่ได้ถ้วยนี้น้อยกว่า 5%" ไม่มีลีดเดอร์บอร์ด |
| R8 | **ถ้วยลับไม่ล่อให้ทำสิ่งที่ไม่ปลอดภัย** ถ้วยที่เกี่ยวกับเวลาดึกหรือเช้ามืดซ่อนสำหรับอายุต่ำกว่า 18 ถ้วยอาบน้ำเย็นซ่อนเมื่อมีข้อจำกัดด้านสุขภาพ |
| R9 | **ท่าที่นับต้องมาจากรายการท่ามาตรฐานของแอป** (เช่น `pushup`, `squat`, `plank`) ไม่ใช่ข้อความที่พิมพ์เอง |
| R10 | **XP จากถ้วยไม่นับ Soft Cap รายวัน** เหมือน Quest และ Milestone และได้ครั้งเดียวต่อใบ |
| R11 | **ถ้วยที่ผู้ใช้ไม่มีโอกาสได้เพราะตั้งค่าไว้ต่างจากที่ถ้วยต้องการ** (เช่น ปิดเควสต์อาบน้ำเย็น) จะไม่แสดงในห้องถ้วยรางวัล ไม่ถือว่าพลาด |

## 3. ระดับถ้วยและรางวัล

| ระดับ | XP | ความหมาย | การแจ้งเตือน (ตาม Celebration ในเอกสารหลัก) | ของแถม |
|---|---|---|---|---|
| 🥉 ทองแดง | 25 | ก้าวแรกหรือการลองของใหม่ | ป้ายเล็กด้านบนหน้าจอ 2 วินาที | ตราในห้องถ้วยรางวัล |
| 🥈 เงิน | 75 | ทำซ้ำจนเริ่มเป็นนิสัย | ป้ายเล็ก + เสียงสั้น (ปิดได้) | ตรา + เลือกแสดงบนโปรไฟล์ได้ |
| 🥇 ทอง | 200 | ความต่อเนื่องระยะยาว | การ์ดเต็มกว้าง ระดับ 4: Milestone Achievement | ตรา + ปลดล็อกสีธีมหนึ่งชุด |
| 💎 ตำนาน | 500 | หมุดหมายใหญ่ ใช้เวลาหลายเดือนถึงหลายปี | เต็มจอ + Haptic (ปิดได้) | ตรา + กรอบโปรไฟล์ + ฉายาที่เลือกใช้ได้ |

ถ้าปลดล็อกหลายใบพร้อมกันในการกระทำเดียว (เช่น เลเวลอัปแล้วได้ถ้วยเลเวลกับถ้วยสะสมพร้อมกัน) ให้แสดงแบบเต็มจอเฉพาะใบระดับสูงสุด ที่เหลือรวมเป็นบรรทัดสรุป "ปลดล็อกอีก 2 ใบ" แตะเพื่อดู

## 6. โครงสร้างข้อมูลและวิธีตรวจ

### 6.1 ต่อยอดตาราง `achievement` เดิม

ตารางเดิมใน `Awakened.md` ข้อ 10.2 มีแค่ `id, title_th, title_en, description, icon, category` ให้เพิ่มคอลัมน์เหล่านี้ (ถ้ายังไม่เริ่มเขียนโค้ด ใส่ใน `CREATE TABLE` ได้เลย)

```sql
ALTER TABLE achievement ADD COLUMN tier TEXT NOT NULL DEFAULT 'bronze';   -- bronze|silver|gold|legend
ALTER TABLE achievement ADD COLUMN xp INTEGER NOT NULL DEFAULT 25;
ALTER TABLE achievement ADD COLUMN stat TEXT;                              -- STR|VIT|INT|WIL หรือ NULL
ALTER TABLE achievement ADD COLUMN hidden INTEGER NOT NULL DEFAULT 0;
ALTER TABLE achievement ADD COLUMN phase INTEGER NOT NULL DEFAULT 1;
ALTER TABLE achievement ADD COLUMN criteria_json TEXT NOT NULL;           -- {metric, op, target}
ALTER TABLE achievement ADD COLUMN hide_for_minor INTEGER NOT NULL DEFAULT 0;
ALTER TABLE achievement ADD COLUMN excluded_flags TEXT;                   -- JSON array ของ safety flag

-- ตัวนับ metric กลาง อัปเดตใน transaction เดียวกับการบันทึกกิจกรรม
CREATE TABLE metric_counter (
  metric TEXT PRIMARY KEY,
  value REAL NOT NULL DEFAULT 0,
  updated_at INTEGER NOT NULL
);
```

`achievement_unlock` เดิมใช้ต่อได้เลย (PK คือ `achievement_id` จึงปลดล็อกซ้ำไม่ได้)

### 6.3 วิธีตรวจ

1. ทุกครั้งที่บันทึกกิจกรรม Engine อัปเดต `metric_counter` ตามกฎเพดาน R5 และ R4
2. หลังอัปเดต ตรวจเฉพาะถ้วยที่ `criteria.metric` เป็น metric ที่เพิ่งเปลี่ยน (ไม่ไล่ตรวจทั้ง 199 ใบทุกครั้ง)
3. ถ้าเงื่อนไขผ่านและยังไม่มีใน `achievement_unlock` ให้เขียน unlock + `xp_event` (`source_type = 'achievement'`, `reason_key = id`) ใน transaction เดียวกัน
4. XP จากถ้วยอาจทำให้เลเวลอัป ซึ่งอาจปลดล็อกถ้วยเลเวลต่อ ให้วนตรวจซ้ำจนไม่มีใบใหม่ (จำกัดไม่เกิน 5 รอบกันวนไม่รู้จบ)
5. ส่งรายการที่ปลดล็อกให้ชั้น UI แสดงตามกฎการรวมแจ้งเตือนในข้อ 3

```dart
List<Achievement> checkAchievements(Set<String> changedMetrics, UserContext u) {
  final unlocked = <Achievement>[];
  for (var round = 0; round < 5; round++) {
    final candidates = catalog.where((a) =>
        !u.unlockedIds.contains(a.id) &&
        changedMetrics.contains(a.criteria.metric) &&
        a.isVisibleFor(u.ageBand, u.safetyFlags) &&
        a.criteria.isMet(metrics.value(a.criteria.metric)));
    if (candidates.isEmpty) break;
    for (final a in candidates) {
      unlock(a);                       // เขียน unlock + xp_event
      unlocked.add(a);
    }
    changedMetrics = {'level_reached', 'achievements_unlocked_total', 'rank_reached'};
  }
  return unlocked;
}
```

เป็น Pure Dart ไม่พึ่ง UI ทดสอบได้ด้วย Unit Test เหมือน Engine อื่น

### 6.4 ชุดทดสอบที่ควรมี

## 8. คำถามที่ต้องตัดสินใจต่อ

1. **สเกลของค่า STR/VIT/INT/WIL ยังไม่ได้กำหนด** ถ้วยหมวดค่าสถานะใช้เลข 25/50/100 เป็นตัวสมมติ ต้องกำหนดว่าค่าแต่ละตัวเพิ่มครั้งละเท่าไรก่อน แล้วค่อยปรับเลขให้ได้ราว 2–6 เดือนสำหรับระดับเงินถึงทอง
2. **XP ต่อระดับถ้วย (25/75/200/500)** เป็นค่าตั้งต้น ถ้าอยากให้ถ้วยมีน้ำหนักกับเลเวลมากขึ้นหรือน้อยลง ปรับได้ที่ `tier_xp` ใน JSON ที่เดียว
3. **ถ้วยตามเทศกาลไทย** ตอนนี้มีแค่ปีใหม่กับสงกรานต์ อยากเพิ่ม (ลอยกระทง วันพ่อ วันแม่ ฯลฯ) หรือไม่ อาจกลายเป็นงานดูแลต่อทุกปี
4. **ถ้วยที่เกี่ยวกับผู้เยาว์:** ตอนนี้ซ่อนแค่ 2 ใบสำหรับอายุต่ำกว่า 18 ถ้าจะรองรับกลุ่มนี้เต็มรูปแบบ ควรตรวจทั้งแค็ตตาล็อกอีกรอบกับผู้เชี่ยวชาญหรือผู้ปกครองที่ทดสอบ
5. **ชื่อถ้วยภาษาอังกฤษ:** ร่างให้ครบแล้วแต่ยังไม่ได้ให้เจ้าของภาษาตรวจ
6. **เก็บถ้วยไหนไว้ใน Phase 1:** ตัวเลขในข้อ 1 บอกว่าถ้วยที่ทำได้ตั้งแต่ Phase 1 มีกี่ใบ ถ้าอยากเริ่มเล็กกว่านั้น ยูนะคัดชุด 30–40 ใบแรกให้ได้
